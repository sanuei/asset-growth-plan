# 《乔布斯传》人物传记短视频系列 · 计划

> 依据：沃尔特·艾萨克森《史蒂夫·乔布斯传》（中信 2011 中译本，41 章，正文约 46 万字）。
> 计划日期：2026-10-17。原书 PDF 和分章文本在 `原书/`，只留在本地，不进 git。文件夹规则见 `README.md`。

---

## 一、先说结论

- **规模**：41 章一共挑出 **96 个故事**，每个故事做成一条 Shorts。按每天 2 条算，大约 **48 天**播完。以后可以再挖到 120 条以上。
- **单条形式**：一条只讲**一个完整的故事**，不讲章节摘要。结构是「钩子 → 场景 → 冲突/细节 → 反转 → 一句带走的道理 → 留言问题」，长度 **55～75 秒**。
- **想做到「全网最好」，要做出和别人的差别**：细节要真（数字、对白、人名都和书核对过），讲人性的两面（不神化他），每条都留下一个能用的道理，画面用真实照片和统一的漫画插画。
- **先做 3 条样片**给你看，定下模板以后再批量生产（见第六节）。

---

## 二、这本书为什么适合拆成短视频

1. **故事密度极高**：每一章都有 3～6 个能独立成立的小故事，而且大多自带数字和对白。比如「600 万股」「350 美元的支票」「80 万美元的广告时段」「5 种面罩」。
2. **人物很矛盾**：天才和混蛋、被遗弃和遗弃别人、极简和控制欲。冲突感强，天然适合做钩子。
3. **有现成的叙事主线**：被遗弃 → 车库创业 → 30 岁被赶出公司 → 荒野 11 年 → 王者归来 → 和癌症搏斗 → 留下遗产。观众会一路追下去。
4. **和频道定位接得上**：书里有大量**钱、股权、估值、谈判**的真实案例，比如韦恩 800 美元卖掉 10% 的股份、施乐用 100 万美元换参观、科特基没拿到期权、皮克斯上市。资产增长计划的观众能学到东西。

## 三、每条短视频的标准

### 3.1 结构（约 55～75 秒，280～360 字，按 1.1 倍速每分钟约 295 字算）

| 时间 | 作用 | 说明 |
|---|---|---|
| 0–3 秒 | **钩子** | 第一句就说最反常识的事实或数字，同时画面中间弹出大字（`flash`）。不铺垫，不说「今天我们来聊」。 |
| 3–15 秒 | 场景 | 年份、地点、人物，一句话把观众带进现场。 |
| 15–45 秒 | 冲突和细节 | 2～3 个硬细节：数字、原话、具体动作。 |
| 45–60 秒 | 反转或后果 | 结局，或者「多年后才知道……」。 |
| 60–70 秒 | **一句带走的道理** | 知识点：商业、投资、做人或做产品的道理，一句话说完。 |
| 最后 | 留言问题 | 例如「换成你，会拿那 800 美元吗？」 |

### 3.2 质量要求（和别人拉开差距的地方）

1. **一条一个故事，讲透**：不做「乔布斯的 10 个冷知识」那种清单。
2. **细节必须核对**：每条写完都要回原书分章文本核对数字和原话。书里本身有争议的地方要讲明白，例如打砖块：沃兹记得是 350 美元的支票，乔布斯否认，书里写的是「多数版本」。照实说，可信度更高。
3. **讲两面**：他的残酷、不认女儿、拒绝给老朋友期权、拒绝手术 9 个月，都要讲。只讲光环的频道太多了，讲真实的人才会让人记住。
4. **每条都有一个道理**：这是「内容第一」原则落到短视频上的做法。观众看完要能说出「我学到了什么」。
5. **不读原文**：全部用我们自己的话重新讲。原书引语每条最多一两句短句，并注明出处。

### 3.3 画面

- **真实照片优先**：Wikimedia Commons 上的乔布斯、沃兹、盖茨、产品（Apple I、Apple II、Mac、iMac、iPod、iPhone）、地点（洛斯阿尔托斯车库、里德学院、皮克斯园区）照片，在描述栏署名。
- **网页截图**：当年的新闻报道、维基百科、SEC 文件、苹果官网新闻稿，用现有的 `web_shot.py`。
- **漫画风插画**：用来画「没有照片的场景」，例如蓝盒子打给梵蒂冈、比萨店被枪指着、董事会政变。沿用 `image_style_comic.txt`。**真人一律画成明显的漫画风，不做照片级的写实图**，也不编造他没说过的话。
- **不用苹果的发布会视频和《1984》广告原片**（有版权）。需要的话用截图配解说，或者用插画重现。
- **系列识别**：纸张质感、黑色高领衫剪影、朱红印章。钩子纸条卡上写「年份 · 地点」（例如「1976 · 洛斯阿尔托斯車庫」），不写集数，不写编号。

### 3.4 用语（2026-10-17 频道主改定：保持书中的简体中文）

- 本系列的画面文字、字幕、配音稿、标题，一律用**原书简体中文和原书译名**（乔布斯、沃兹尼亚克/沃兹、盖茨、斯卡利、乔尼·艾弗、蒂姆·库克、施乐、麦金塔……）。这条只适用于本系列，频道其他视频仍用繁体。
- 配音前用 MiniMax 的 `pronounce_text` 抽查人名读音（免费）。

## 六、执行步骤

### 第 0 步：做 3 条样片（先给你看，定模板）
挑三种类型，看哪种效果最好：
1. **故事型**：#13「4 天沒睡，只拿到 350 美元」（友情和背叛）
2. **金钱型**：#16「800 美元賣掉 10%，後來值 26 億」（最贴合资产增长计划的定位）
3. **人性/金句型**：#26「開機快 10 秒，等於救 100 條命」

你看完以后定下：长度、钩子卡样式、插画和照片的比例、结尾要不要「系列感」。

### 第 1 步：批量生产
- 每条按现有的独立 Shorts 流程做：`第XX章_章名/08_Shorts/<编号>/01_文案/script.json` → `tts_episode.py` → `shorts.json` → `shorts.py`（步骤和命名见 `README.md`）。
- 一次写好一整幕的稿子，逐条回书核对，再一次性配音，避免返工。
- 每条至少 3 个画面：开头 3 秒内要切到第二个画面。

### 第 2 步：发布
- 每天 2 条，建议沿用 12:00 和 18:00（台湾时间）。
- 播放清单：「賈伯斯傳：100 個改變世界的真實故事」，按六幕排序。
- 标题照频道规则写长，体现利他，结尾加 `#Shorts`。例如：
  - 「他 4 天沒睡寫出經典遊戲，卻只拿到 350 美元：賈伯斯和沃茲之間最痛的一次背叛 #Shorts」
  - 「蘋果第三位創辦人用 800 美元賣掉 10% 股份，如今價值 26 億：你會怎麼選？ #Shorts」
- 描述栏写：资料来源（沃尔特·艾萨克森《賈伯斯傳》第 X 章，加上交叉核对的来源）、图片署名、免责声明。

### 第 3 步：复盘
- 每发完 10 条，看一次留存率和完播率，找出哪种钩子、哪种类型表现最好，调整后面的顺序。

## 八、风险和注意事项

1. **版权**：书是受版权保护的作品。我们只讲事实和故事，**用自己的话重新讲**，不朗读原文，不展示书页，引语只用短句并注明出处。原书 PDF 和分章文本都不上传 GitHub。
2. **真人形象**：漫画风插画不画成以假乱真的样子，也不编造他没说过的话、没做过的事。
3. **争议事实**：书里也有当事人各执一词的地方（打砖块奖金、丽萨的事），要讲明「谁说了什么」，不替他下结论。
4. **用语统一**：本系列一律用原书简体和原书译名（乔布斯），不要混用台湾译名。

## 九、需要你决定的事

1. **放在哪个频道？**
   - A. 放在资产增长计划，作为一个固定系列（优点：马上有流量；缺点：频道定位会从「投资」变宽）。
   - B. 新开一个人物传记频道（优点：定位清楚，以后可以做马斯克、巴菲特、芒格；缺点：从零开始，还要设置 OAuth 和品牌）。
2. **单条长度**：照现在的 45～55 秒，还是放宽到 55～75 秒，好把故事讲完整？（建议样片做 60～70 秒试试。）
3. **结尾要不要系列感**：例如最后一句「下一個故事，他遇見了沃茲」。这能带动连看，但和长视频「不预告下集」的规则不一样，需要你确认。
4. **要不要做每幕一支的长视频**。
