# EP001｜巴菲特給普通人的投資建議

频道第一期，标杆视频。

## 文件夹

| 文件夹 | 内容 |
|---|---|
| `01_文案/` | `script.json`（制作用：段落 + 画面安排）、`文案.md`（阅读用） |
| `02_配音/` | `segments/` 逐段配音 mp3 + 逐字时间戳；`voice_full.wav`、`bgm.wav`、`mix.wav`（仅本地） |
| `03_画面素材/` | `场景图/`（gpt-image-2 生成 + `prompts.json`）、`图表/`（图表与文字卡预览）、`graphics.json`（图表规格） |
| `04_字幕/` | `EP001.srt`（繁体中文，可上传为 YouTube 字幕） |
| `05_封面/` | 主封面（白黄）、备选封面（白红，可做 A/B 测试）、封面背景 |
| `06_成片/` | 成片 mp4（仅本地，超过 GitHub 单文件上限） |
| `07_发布信息/` | 标题（含备选）、描述（含章节与资料来源）、标签、`upload.json` |
| `99_工作文件/` | `sources/` 股东信原文；渲染中间文件（仅本地） |

## 重新生成

```bash
.venv/bin/python pipeline/tts_episode.py "videos/EP001_巴菲特給普通人的投資建議"
.venv/bin/python pipeline/images_episode.py "videos/EP001_巴菲特給普通人的投資建議"
.venv/bin/python pipeline/assemble.py "videos/EP001_巴菲特給普通人的投資建議"
```

改了某段文案后，只需要用 `--only pXX --force` 重新配音那一段，再删掉 `99_工作文件/clips/` 重新合成。

## 事实核查

所有数据与引述的出处见 `07_发布信息/描述.txt` 的「資料來源」，股东信原文在 `99_工作文件/sources/`。
